# Form/Text-field

## States

- `Unfilled`
- `On tap`
- `Typing`
- `Filled`

## Rules

- Focus ring must map to `color/border/focus`.
- Placeholder and filled text use different semantic text levels.
- Keep keyboard and screen-reader behavior unchanged while updating visuals.
