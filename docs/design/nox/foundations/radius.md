# Radius

- `radius-none`
- `radius-s`
- `radius-m`
- `radius-full`

## Extracted primitive values

| Token | Value |
|---|---|
| `radius/none` | `0` |
| `radius/s` | `4` |
| `radius/m` | `12` |
| `radius/full` | `999` |

## Usage rules

- Controls default to `radius-m` unless design specifies otherwise.
- Pills/chips/tags use `radius-full`.
- Reserve `radius-none` for edge-aligned or intentionally sharp surfaces.
