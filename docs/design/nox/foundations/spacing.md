# Spacing

## Semantic spacing

- `Header`: `16px` (header to first element)
- `Group`: `16px` (inside same thematic group)
- `Section`: `32px` (between distinct sections)
- `Category`: `8px` (category title to content)
- `Footer`: `24px` (content to bottom fixed area)

## Usage rules

- Use semantic names in design decisions first, then map to implementation utilities/tokens.
- Avoid adding one-off spacing values unless they are promoted as new tokens.
