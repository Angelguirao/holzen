# Patterns

This folder tracks composed patterns and extensions not yet covered as first-class Nox components.

## Rules

- Extensions must visually and behaviorally align with Nox tokens/components.
- No legacy Holzen style should remain once the corresponding area is migrated.
- Each extension should include: purpose, anatomy, states, and token usage.

## Current candidates from Figma composed demos

- Alerts
- Badges
- Progress cards/bars
- Switch/checkbox/slider groups
- Interaction patterns (tooltip/modal/accordion)
- Investment panel compositions
- Evaluation scales (Likert variants)
